# Resolve private travel preferences

Retrieve the traveller’s current preferences and document locations from the active conversation, private personal context or authorised connected records. Do not assume a nationality, passport, itinerary, spending limit or seat preference from this public plugin.

Before a seat change, establish the preferred seat type for each leg, acceptable cabin location, excluded seats and maximum charge. Preserve all explicit constraints throughout the task and tell airline staff the complete requirements. Verify the actual aircraft layout before describing a row as forward or rear.

Before booking or check-in, find the current original travel documents in authorised connected files. Do not ask for another upload until available sources have been checked. Keep passport data, file identifiers and personal preferences in private records rather than this public repository.
